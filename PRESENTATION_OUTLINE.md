# 7-Minute Judge Presentation

## 0:00–0:45 — Problem
International students manage multiple currencies, tuition deadlines, monthly spending plan and transfers. Existing chatbots can explain finances but usually cannot safely complete a task.

## 0:45–1:15 — Product
BorderWise AI is an agentic cross-border student finance assistant.

Tagline:
"Not just advice. A financial agent that can reason and act safely."

## 1:15–3:30 — Live demo
1. Reset demo.
2. Ask: "Can I afford my tuition?"
3. Agent observes balances, income and obligations.
4. Forecast identifies the current 30-day shortfall.
5. Agent recommends a MYR → SGD conversion based on the displayed reference FX rate while preserving the RM5,000 emergency reserve.
6. Agent prepares Level-2 proposal.
7. User authorizes.
8. Sandbox transaction executes.
9. Verification updates balances.
10. Audit trail records the action.

## 3:30–4:30 — Prove it is not scripted
Ask:
- "What are my biggest expenses?"
- "Will I run out of SGD?"
- "What are my recent transactions?"
- "How much money do I have?"

## 4:30–5:30 — Security
Show permission tiers and deliberately attempt RM26,000 transfer. Demonstrate policy block.

Core statement:
"The AI proposes. The deterministic policy engine decides whether it is safe. The user authorizes. Only then can the sandbox execute."

## 5:30–6:30 — Innovation
Agentic tool selection, multi-currency reasoning, financial forecast, risk-aware execution and auditability.

## 6:30–7:00 — Closing
BorderWise turns cross-border student finance from a question-answering experience into a controlled agentic workflow.
