# BorderWise AI v6.1

Judge-facing UX upgrade built on v6.0.

- Added a visible Judge Journey: Observe → Reason → Recommend → Authorize → Execute → Verify + Audit.
- Judge Mode buttons now explain what each scenario demonstrates.
